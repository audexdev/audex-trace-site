Privacy

Audex Trace Privacy

Playback format detection is designed to run locally on your Mac. Network use is limited to product functions that need it.

Summary

Built for your Mac, not for tracking.

Audex Trace does not modify, enhance, record, or upload your audio.

No listening history is uploaded for audio-quality detection.

No Apple Music account sign-in or cloud library API access is required.

Website download and checkout events may be counted with minimal, non-audio attribution data so Audex can understand release demand.

Local processing

What runs on your Mac.

Playback format detection runs locally on your Mac.

Compatibility Check is a free manual diagnostic surface so you can test playback-format detection before buying Pro.

Auto Sample Rate Match is an experimental Pro feature that can update the selected macOS output rate when your output device exposes a compatible sample rate.

Network use

When Audex Trace may use the network.

License verification may contact Audex services.

Purchase checkout uses the Audex checkout redirect service.

Update checks use Audex Trace's public update feed.

Artwork fallback may send track, artist, or album search terms to the iTunes Search API when local artwork sources miss.

The website and checkout service may record source/ref/UTM parameters, anonymous browser and session IDs, release version, landing page, referrer host, coarse country, optional salted IP hash, and Stripe Checkout session ID for download and purchase conversion counts.
