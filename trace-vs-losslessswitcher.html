Audex Trace vs LosslessSwitcher: what's different.

LosslessSwitcher is a useful free tool for automatic sample-rate switching. Trace is for Apple Music listeners who also want to see what is playing, whether the output matches, and, in Trace Pro, what is coming up next in Playing Next.

If automatic switching is all you need, use LosslessSwitcher.

LosslessSwitcher is free and open source, and it does the one thing most people want: it switches your DAC's sample rate to match what Apple Music is playing. You do not need to pay for that.

LosslessSwitcher switches. Trace also shows what is playing.

LosslessSwitcher is built around automatic sample rate switching. Trace is built around showing the codec, sample rate, and bit depth of what is playing and whether your output matches it, and it switches sample rates too.

When the rate changes around a track change.

Music prepares the next track before the current one ends, and the prepared track writes its format to the log while the current one is still playing. It does this with Song Transitions, AutoMix, and Crossfade off too, so turning them off does not prevent an early switch. Two open LosslessSwitcher issues describe what happens when a switcher applies that line. In #159 (January 2025), the bit depth and sample rate follow the next song in the playlist instead of the one playing. In #231 (September 2026), the rate is right at the start of a track and then changes partway through to the next track's rate. Pull request #225, which would run detection only on a real track change, resume, or seek, was still open and unreleased on November 3, 2026.

Trace's readout and Auto Sample Rate Match stay on the track that is playing until the next one starts, so a prepared next track does not move them. This is best effort. Within a track the readout is live: if Music's stream drops to a lower quality partway through a song, or comes back up, the readout changes when that happens. The mid-track switch guide has more on the problem and how to check for it.

Song Transitions, AutoMix, and Crossfade cause a separate delay. With one of them on, Music plays two tracks at once around each change. Trace's readout still changes when the next track starts. Auto Sample Rate Match waits until Music has finished handing over from the previous track, because changing the rate mid-blend makes Music cut the blend off and start it again. So the switch can land a few seconds after the track change, up to about 20 seconds in the worst case, and macOS resamples the new track until then. The developer tested this with AutoMix on macOS 26; macOS 15 has not been checked with these features on.

Check your own Mac before paying.

Detection and readout accuracy vary across DACs, interfaces, and configurations.

Trace's free Playback Verification is there for that. Download it, play a few tracks, and compare what Trace reports with your DAC's own display. If the numbers match on your Mac and your hardware, buy Pro. If they do not, you do not need to pay.

Before you download

Playback-format detection currently requires a macOS administrator account. Standard user accounts cannot access the local playback logs Trace needs, so Playback Verification and live playback-format detection do not work there.

What about SyncHz (formerly Choritsu)?

SyncHz is another free, open-source option: a menu-bar app for macOS 15 and later that works with Apple Music only. It handles automatic sample-rate switching by reading Music's own log, and its README describes it as the same core idea as LosslessSwitcher in a different build.

It also adds a driverless parametric headphone EQ with AutoEq and PEQdB presets, a now-playing panel, device and volume control, and 12 languages. Its README notes that playback is not bit-perfect while the EQ is on.

For detection, its README says it reads Music's log, locks a rate only after enough evidence, resets the lock on every track change, and is debounced so it does not flap mid-track. The README does not say how it handles a prepared next track or Song Transitions, AutoMix, and Crossfade. SyncHz is not notarized yet, so the README has you clear the quarantine flag in Terminal before the first launch; Trace is signed and notarized.

Its panel also shows source and output side by side with the codec, bit depth, and Apple's quality tier, so on the readout itself the two tools overlap. What SyncHz's README does not describe is Trace Pro's Playing Next: the upcoming queue, artwork, quality estimates, and skip warnings. Trace has no EQ, and Trace Pro is a $29.99 one-time purchase. If automatic switching plus a headphone EQ is what you want, SyncHz is a good free choice.
