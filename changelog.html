1.2

May 29, 2026

GitHub Release

Feature update for Apple Music listeners on macOS 15 and later, focused on seeing what is coming next and catching playback-quality issues earlier.

Download AudexTrace-1.2.zip, unzip it, and move Audex Trace.app to /Applications.

What's new

  • Added Playing Next, a compact queue view for upcoming Apple Music tracks.
  • Added queue quality estimates so upcoming tracks can show estimated Lossless or Hi-Res availability before playback reaches them.
  • Added skip warnings for queued tracks that look likely to fail or be skipped by Apple Music.
  • Added Playing Next preferences so queue, quality, and skip-warning surfaces can be controlled from the app.

Quality detection and reliability

  • Reduced audio-quality log-stream CPU load by filtering capture to Music.app and waiting for capture shutdown cleanly.
  • Added startup backfill for skip detection so the current track can recover recent skip signals after Trace restarts.
  • Isolated Compatibility Check from live quality detection so manual checks do not mutate the current playback-quality state.
  • Hardened MediaRemote queue handling, artwork recovery, stale stream termination, and adapter JSON parsing.
  • Coalesced Music refresh requests to avoid redundant full snapshot refreshes after notifications and local commands.

UI polish

  • Refined compact player controls, footer alignment, artwork fallback, and playback transitions.
  • Improved Playing Next layout after UI scale changes and preserved compact queue position after dragging.
  • Improved menu bar controls and notch artwork/playback-state transitions.
  • Kept playback readout, output match status, and experimental Auto Sample Rate Match aligned with the v1.2 Pro feature set.

Release and compatibility

  • Signed and notarized Developer ID build 24.
  • Added a dedicated Distribution build configuration and removed Local Network / Bonjour prompts from release builds.
  • Fixed release packaging so the production MediaRemote queue adapter is signed for notarization.
  • Requires macOS 15 or later.
  • For best real-time playback-format detection, turn off Song Transitions, AutoMix, or Crossfade in Music.
  • Auto Sample Rate Match depends on the output device exposing compatible macOS sample rates.
  • Audex Trace currently supports local Apple Music playback on the Mac. The iPhone Remote feature is not included in this public release.

First public release

1.0

May 23, 2026

GitHub Release

Initial public release for macOS 15 and later.

Download AudexTrace-1.0.zip, unzip it, and move Audex Trace.app to /Applications.

Highlights

  • Apple Music mini player with playback controls, track metadata, and album artwork.
  • Menu bar controls with playback-status visuals.
  • Optional notch overlay for quick now-playing access.
  • Local playback format detection for Apple Music, including codec, bit depth, and sample rate.
  • Output sample-rate match status for Pro users.
  • Experimental Auto Sample Rate Match for Pro users.
  • Built-in Compatibility Check so users can verify playback-format detection before buying Pro.
  • Signed and notarized Developer ID build distributed through GitHub Releases.
  • Sparkle update support using the production appcast at https://trace.audex.dev/appcast.xml.

Before buying Pro

  • Run the built-in Compatibility Check on your own Mac.
  • For best real-time playback-format detection, turn off Song Transitions, AutoMix, or Crossfade in Music.
  • Auto Sample Rate Match depends on the output device exposing compatible macOS sample rates.

Known limitations

  • Apple Music can prepare upcoming tracks before playback starts, so Song Transitions, AutoMix, or Crossfade may make format detection delayed or unavailable around track changes.
  • macOS 14 and earlier are not officially supported.
  • Audex Trace currently supports local Apple Music playback on the Mac. The iPhone Remote feature is not included in this public release.
