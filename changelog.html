1.2

May 29, 2026

GitHub Release

Feature update for Apple Music listeners on macOS 15 and later, centered on Playing Next and earlier visibility into upcoming playback issues.

Download AudexTrace-1.2.zip, unzip it, and move Audex Trace.app to /Applications.

What's new

  • Added Playing Next, a compact queue view for upcoming Apple Music tracks.
  • Playing Next is available for free with upcoming track metadata and artwork.
  • Pro users can now see estimated queue quality for upcoming tracks, including Lossless, Hi-Res, or Dolby availability before playback reaches them.
  • Pro users can now see skip warnings for queued tracks that look likely to fail or be skipped.
  • Added Playing Next preferences so queue details, quality estimates, and skip warnings can be shown or hidden.

Improvements

  • Reduced CPU usage while audio-quality features are active.
  • Improved queue refresh behavior and artwork stability around track changes.
  • Improved compact player layout, footer alignment, and playback transitions.
  • Refined menu bar and notch presentation for the new queue experience.
  • Improved Preferences organization with a clearer Support and Feedback area.

First public release

1.0

May 23, 2026

GitHub Release

Initial public release for macOS 15 and later.

Download AudexTrace-1.0.zip, unzip it, and move Audex Trace.app to /Applications.

Highlights

  • Apple Music mini player with playback controls, track metadata, and album artwork.
  • Menu bar controls with playback-status visuals.
  • Optional notch overlay for quick now-playing access.
  • Local playback format detection for Apple Music, including codec, bit depth, and sample rate.
  • Output sample-rate match status for Pro users.
  • Experimental Auto Sample Rate Match for Pro users.
  • Built-in Compatibility Check so users can verify playback-format detection before buying Pro.
  • Signed and notarized release distributed through GitHub Releases.
  • Automatic update support for future releases.

Before buying Pro

  • Run the built-in Compatibility Check on your own Mac.
  • For best real-time playback-format detection, turn off Song Transitions, AutoMix, or Crossfade in Music.
  • Auto Sample Rate Match depends on the output device exposing compatible macOS sample rates.

Known limitations

  • Apple Music can prepare upcoming tracks before playback starts, so Song Transitions, AutoMix, or Crossfade may make format detection delayed or unavailable around track changes.
  • macOS 14 and earlier are not officially supported.
